# Images Folder

This folder contains all the images used in the portfolio website.

## Required Images

### Portrait Image
- **Filename**: `five_year_old_rm.jpg` (or `.png`, `.jpeg`)
- **Location**: Place in this folder (`images/`)
- **Recommended size**: 800x1000px or similar 3:4 aspect ratio
- **Format**: JPG, PNG, or WebP
- **Description**: Your portrait photo for the hero section

## Supported Image Formats

The website supports the following image formats:
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

## Adding Your Portrait Image

1. Place your portrait image in this folder
2. Name it `five_year_old_rm.jpg` (or update the filename in `index.html` line 55)
3. If using a different extension (like `.png`), update the HTML:
   ```html
   <img src="images/five_year_old_rm.png" alt="Komil Parmar - ML Enthusiast" class="portrait-image">
   ```

## Image Optimization Tips

For best performance:
- Use WebP format for smaller file sizes
- Optimize images before uploading (compress without losing quality)
- Recommended max width: 800px
- Keep file size under 500KB if possible

## Future Images

As you expand your portfolio, you can add more images here:
- Project screenshots
- Blog post images
- Certification badges
- Event photos
- etc.

All images should be added to this folder and referenced as `images/filename.ext` in your HTML.
